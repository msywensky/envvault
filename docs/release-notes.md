Installers for Windows (`-setup.exe`) and macOS (`.dmg`). Check each download against its `.sha256` file.

**These builds are not code-signed.** Windows SmartScreen and macOS Gatekeeper will warn on first run; the README's [Install](https://github.com/msywensky/envvault#install) section says how to continue. There is no auto-update.

0.x releases may change the settings file or the vault format between versions; read [CHANGELOG.md](https://github.com/msywensky/envvault/blob/main/CHANGELOG.md) before upgrading a vault you rely on.

Report a vulnerability privately, as described in [SECURITY.md](https://github.com/msywensky/envvault/blob/main/SECURITY.md).
